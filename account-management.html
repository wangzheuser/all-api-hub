账号管理

本文介绍账号添加完成后的整理、维护和批量操作。要添加新账号或查找手动填写方法，请查看 添加账号。

添加账号

建议先使用自动识别；如果识别失败，也可以手动填写 New API、Sub2API 或 OpenRouter 等站点所需的信息。

  • 查看完整的添加账号指南
  • 直接前往手动添加说明

1. 重复账号清理

如果你不小心添加了许多重复的账号，可以使用内置的清理工具：

  1. 进入 “账号管理” 页面，在顶部点击 “扫描重复账号”。
  2. 在 “重复账号清理” 对话框中查看结果。不同地址下的疑似重复账号需逐项核对，不参与批量清理。
  3. 插件会根据 URL 源站 + 用户 ID 对账号进行分组；另外还存在按相同管理密钥分组。
  4. 你可以选择 3 种保留策略 之一，也可以手动选择要保留的账号。
  5. 清理前需要二次确认。

2. 账号组织与排序

随着账号数量增加，你可以通过以下方式保持列表整洁：

2.1 标签 (Tags)

  • 为账号添加标签（如 工作, 个人, 中转, 官网）。
  • 在面板顶部通过标签快速过滤。
  • 标签系统与书签、API 凭据库共享，支持全局重命名。

2.2 置顶 (Pinning)

  • 打开账号右侧的 “…” 更多菜单，选择 “置顶账号”。
  • 已置顶的账号可以通过同一菜单选择 “取消置顶”。
  • 已置顶的账号会在行内显示 Pin 状态标识。
  • 同一浏览站点优先层级内，置顶账号显示在普通账号之前；当前站点和相关页面已打开的账号可能排在其他置顶账号之前。已禁用账号始终在末尾。

2.3 排序优先级

  • 在 设置 → 账号管理 → 排序优先级设置 中，分别控制当前站点和已打开相关页面的账号是否优先显示；修改后自动保存。
  • 在列表的 排序方式 菜单选择账号名称、余额、今日消费、今日收入、签到需求、健康状态、自定义签到或兑换链接、创建时间，再切换排序方向。
  • 重置默认排序 清除字段排序，保留浏览站点开关和已保存的手动顺序。
  • 在完整设置页点击 调整顺序 后拖动账号，调整会自动保存。置顶、普通和禁用账号只能在各自分组内排序。
  • 搜索和手动排序模式不应用浏览站点优先规则。详见 排序优先级设置。

2.4 余额与今日收益统计

  • 在新增或编辑账号时，可以开启 “从总余额中排除”，让该账号不参与弹窗、账号列表以及分享总览快照中的总余额汇总；这不会影响账号刷新、签到或列表显示。
  • 如果某个账号的收入不应计入当天汇总，可以开启 “从今日收益中排除”。该开关只影响弹窗、账号列表以及分享总览快照中的今日收益合计，不会隐藏账号，也不会停止刷新或签到。

2.5 单账号“…”菜单

账号右侧的 “…” 菜单集中提供密钥、模型、刷新、签到、相关页面、分享和账号管理操作；具体项目按账号状态和站点能力显示。签到有问题时，也可从这里反馈或申请适配。

禁用状态的账号，“…”菜单仅包含：启用账号、删除。

“快速签到”与“签到配置”

  • 快速签到：点击后会立即调用该账号的内置签到提供方。即使全局每日计划关闭，也可以单独运行，但账号仍需已启用、已检测、账号级“启用每日自动签到”开启，且该站点类型有内置提供方、凭据可用。
  • 签到配置：编辑账号时，表单里的“签到配置”区域——支持内置签到的账号会显示“启用每日自动签到”；所有账号都可以按需填写“外部签到站点 URL”。账号表单没有旧的“签到检测”开关，签到状态在账号刷新/识别时自动读取。
  • 自动签到的完整说明见 自动签到。

3. 健康状态与错误码

插件会实时监测账号的连通性。如果账号卡片显示“警告”或“异常”，通常是因为：

  • 401 Unauthorized: 登录失效或 Access Token 已过期。
  • 429 Too Many Requests: 触发了站点频率限制，插件会自动排队重试。
  • 403 Forbidden: 通常表示触发了 Cloudflare 防护，请参考 Cloudflare 过盾助手。

你可以点击卡片上的健康状态图标查看详细的错误信息。更多常见错误处理请参考 常见问题。

4. 批量操作

在账号管理页面勾选账号后，可使用以下批量操作。切换搜索或标签筛选会保留已选项，删除或禁用前请先查看全部已选账号，核对并取消不需要处理的条目。

  • 全选当前列表：选中当前搜索和标签筛选下的所有账号。

  • 取消选中当前列表：只取消当前筛选结果中的已选账号。

  • 清空全部选择：清空所有已选中的账号。

  • 禁用已选：禁用所有已选中的账号。

  • 复制邀请链接：复制已选中账号的邀请链接。

  • 复制站点地址：复制已选中账号的站点地址，已禁用账号也会一并复制。

  • 删除已选：删除所有已选中的账号（需要二次确认）。

  • 退出批量模式：退出当前的批量操作模式。

  • 0 个账号选中时，相应操作不可用；选中账号后，相应操作才会启用。

  • 复制类操作按列表当前显示顺序输出；被搜索或筛选隐藏的已选账号排在最后。

  • “从书签批量导入”是独立入口，不属于上述勾选式批量工具栏。具体流程请查看 添加账号。
